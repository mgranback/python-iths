## Om Python

Python är ett relativt gammalt språk som används inom många olika områden. Några exempel:

- Verktyg och infrastruktur som håller ihop större system.
- Dropbox skrevs ursprungligen i Python.
- Delar av YouTube och Instagram är byggda i Python.
- Mycket av dagens AI- och maskininlärningsvärld körs på Python.

Det används i spel, databehandling, vetenskapliga beräkningar, webbtjänster med mera —
och inom IT-säkerhet för att automatisera analys av loggar och textdata, vilket är
fokus i den här kursen.

Python är dessutom relativt lätt att lära sig, och ett bra språk att börja programmera med.
